# Security policy

## Reporting a vulnerability

Do not open a public issue for vulnerabilities, credentials, tokens, OAuth
redirect URLs, or unredacted PointT responses. Use GitHub's private
**Security > Report a vulnerability** flow for this repository.

Include the smallest reproducible description possible and remove account,
gateway, serial, network, location, and user-defined naming data. You should
receive an acknowledgement within seven days.

## Supported versions

The project has not published a supported release yet. Security fixes will be
applied to the latest development line until a version support policy is
announced.

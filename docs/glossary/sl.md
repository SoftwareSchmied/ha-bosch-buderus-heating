# Slovenian (sl) glossary

Draft, awaiting review by a native speaker. Based on the glossary in
[`docs/translations.md`](../translations.md); Home Assistant core terms are
used where core already has them (marked HA).

Address: formal plural as in Home Assistant core ("poskusite znova",
"vaša naprava"), lowercase *vi/vaš* inside a sentence. Sentence case.
Button names quoted in texts: **Pošlji** (Submit, HA config flow button),
**Uporabi** (Apply, HA). Date format of notifications: `%d. %m. %Y`

Generated names are built from parts ("Ogrevalni krog 1 – Temperatura
dvižnega voda"), so names and group names stand alone in the nominative.

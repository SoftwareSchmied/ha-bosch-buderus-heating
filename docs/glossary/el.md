# Greek glossary (el)

Draft, awaiting review by a native speaker. The Greek texts in
`translations/el.json` and `i18n/el.json` use these terms consistently; a
correction to one term usually applies to every text that uses it.

Style: sentence case, monotonic accents, formal address (second person
plural: "Επιλέξτε", "Εισαγάγετε"), as Home Assistant uses for Greek. Counts are
written in a neutral form ("Μη αποθηκευμένες αλλαγές: {count}") so that no
plural form is needed. Date format of notifications: `%d/%m/%Y`.

Control names shorten the group, for example "ΚΘ 1: Τρόπος λειτουργίας".
Product, standard and preset names stay as they are: Home Comfort, SingleKey
ID, Eco, Eco+, Boost, SG Ready, Smart Function, Power Guard, PV. "Comfort" is
translated as "Άνεση". Brand names of manufacturers do not appear in labels.

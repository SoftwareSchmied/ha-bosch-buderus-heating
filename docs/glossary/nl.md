# Glossary: Dutch (nl)

Draft, awaiting review by a native speaker. The Dutch texts in
`translations/nl.json` and `i18n/nl.json` use these terms consistently.

Style: sentence case; the user is addressed with "je/jouw", as Home Assistant
does in Dutch. Compounds are written as one word where Dutch spelling requires
it (for example "warmwatertemperatuur", "cloudtoegang").

Product, standard and preset names stay as they are: Home Comfort, Eco, Eco+,
Boost, SG Ready, Smart Function, Power Guard, PV, SingleKey ID. Labels of the
Chrome developer tools quoted in the sign-in steps stay in English.

Date format of notifications: `%d-%m-%Y`.

# Croatian (hr) glossary

Draft, awaiting review by a native speaker. Based on the glossary in
[`docs/translations.md`](../translations.md); Home Assistant core terms are
used where core already has them (marked HA).

Address: formal plural as in Home Assistant core ("Pokušajte ponovno",
"vaš uređaj"), lowercase *vi/vaš* inside a sentence. Sentence case.
Button names quoted in texts: **Podnijeti** (Submit, HA config flow button),
**Primijeni** (Apply, HA). Date format of notifications: `%d.%m.%Y.`

Generated names are built from parts ("Krug grijanja 1 – Temperatura
polaznog voda"), so names and group names stand alone in the nominative.
